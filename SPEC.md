# SPEC — nix-mcp-python-sdk

## §G GOAL

Nix package for the Model Context Protocol Python SDK (`mcp` on PyPI) at 2.x, which nixpkgs lacks. Consumed by nix-semble for semble's MCP server. Pre-built via cachix (`pr0d1r2.cachix.org`).

## §C CONSTRAINTS

- C1: Nix flake, nixpkgs follows `github:pr0d1r2/nixpkgs-lock` (fleet pin, currently `nixos-26.05`)
- C2: Built from source: `mcp` and `mcp-types` from one `modelcontextprotocol/python-sdk` tag; `httpx2` and `httpcore2` from one `pydantic/httpx2` tag
- C3: mcp needs `httpx2>=2.10.0`, and each httpx2 pins `httpcore2` to its own version; both are overridden from nixpkgs' 2.3.0
- C4: `idna>=3.18` relaxed to nixpkgs' 3.15. Gap: `httpx2.URL.host` raises TypeError for punycode hosts; affected tests disabled. Remove once nixpkgs-lock ships idna >= 3.18
- C5: Build-time only: `uv-dynamic-versioning` 0.14.1 (nixpkgs 0.13.0), tests skipped, `dunamai` relaxed
- C6: mcp's own test suite disabled (subprocesses, sockets); `load-server` check covers the protocol round trip
- C7: Guardrails and git hooks come from set-and-setting; `lefthook.yml` is generated by the dev shell, never edited by hand

## §I INTERFACES

- I.pkg: `packages.<system>.{default,mcp,mcp-types,httpx2,httpcore2}`
- I.check: `checks.<system>.load-server` registers a tool on an `MCPServer`, connects an in-memory `Client`, lists and calls the tool
- I.flake-input: `inputs.nix-mcp-python-sdk.url = "github:pr0d1r2/nix-mcp-python-sdk"` w/ `nixpkgs.follows`

## §V VERSIONING

- mcp: `version` and `src` in mcp-python-sdk.nix (currently 2.3.0)
- httpx2/httpcore2: `httpxVersion` and `httpxSrc` (currently 2.16.0)

## §T TESTING

- T1: `nix flake check` runs the set-and-setting guardrails plus `load-server`
- T2: httpx2 and httpcore2 run their upstream test suites
- T3: lefthook pre-commit and pre-push gates

## §B BUILD

- B1: `nix build`, builds mcp for the current system
- B2: `nix develop`, enters the dev shell and installs git hooks
